# The shared chassis: what every SmartFoodOps service needs to start and serve.

# Referenced by each service's own requirements.txt via `-r ../common/requirements.txt`,
# which resolves relative to that file. The Docker build context is ./services, so both
# files are reachable from every service's Dockerfile.
#
# Deliberately NOT here:
#   httpx                          — only services that call a sibling import
#                                     common.service_client, and the User Service calls
#                                     nobody. Listed by the five that do.
#   opentelemetry-instrumentation-httpx
#                                   — same reasoning: only needed alongside httpx itself.
#   temporalio                     — only common.temporal needs it, and only the
#                                     Orchestrator Service imports that.
#   aiokafka, fastjsonschema        — only common.kafka needs them, and only order,
#                                     payment, analytics and notification import that
#                                     (Week 3, D39/D40).
#
# Anything added here is added to all seven images, so a dependency belongs here only when
# a module in common/ imports it unconditionally.
